# Папка ассетов

Ресурсы игры. Загружает их только View-слой через `AssetManager`.

```text
assets/
  images/   # .png — спрайты игрока, платформ, фона
  sounds/   # .ogg / .wav — прыжок, пружина, проигрыш
  fonts/    # .ttf (опционально)
```

Если файла нет, игра рисует простой плейсхолдер и продолжает работать,
поэтому графику можно добавлять постепенно.
