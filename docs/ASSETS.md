# Графика и звук (стиль Minecraft)

Как добавить картинки и звук, сохраняя архитектуру MVC.

## Главное правило
Ресурсы грузит **только View** через `AssetManager` (`src/views/assets.py`).
Модель (`src/models/`) с файлами и pygame не работает.

## Куда класть файлы
```text
assets/
  images/
    player.png            # персонаж: стойка / падение
    player_jump.png       # персонаж: прыжок (полёт вверх)
    background.png        # небо (тайл)
    ground.png            # земля на старте (тайл)
    platform_static.png   # обычная платформа
    platform_moving.png   # движущаяся платформа
    platform_breakable.png# ломающаяся платформа
    platform_spring.png   # платформа-пружина
    coin.png              # монета
    elytra.png            # элитры (ракетный ранец)
    portal.png            # портал (опасная зона)
    menu_bg.png           # фон главного меню
    weapon_bow.png        # пикап: лук (лежит на платформе)
    weapon_pistol.png     # пикап: пистолет
    weapon_rifle.png      # пикап: автомат
    arrow.png             # снаряд лука (стрела)
    bullet.png            # снаряд пистолета/автомата (пуля)
    player_bow.png        # игрок с луком: стойка
    player_bow_jump.png   # игрок с луком: прыжок
    player_pistol.png     # игрок с пистолетом: стойка
    player_pistol_jump.png# игрок с пистолетом: прыжок
    player_rifle.png      # игрок с автоматом: стойка
    player_rifle_jump.png # игрок с автоматом: прыжок
    zombie.png            # враг: зомби (статичный)
    spider.png            # враг: паук (ходит по горизонтали)
    skeleton.png          # враг: скелет (ходит по вертикали, стреляет)
  sounds/
    jump.ogg              # (опционально) звук прыжка
  fonts/
```

Имена файлов заданы в `src/config/constants.py` (`IMAGE_*`).
Если файла нет — рисуется серый плейсхолдер, игра не падает. Можно добавлять
графику постепенно.

## 1) Персонаж и его анимация (2 кадра)
1. Сохрани стойку как `assets/images/player.png` (квадрат, прозрачный фон).
2. Сохрани позу прыжка как `assets/images/player_jump.png`.
3. Запусти игру — спрайты подхватятся автоматически.

Что делает код (`src/views/game_view.py`):
- масштабирует спрайты до размера игрока **пиксельно** (`smooth=False`);
- выбирает позу по скорости: летит вверх (`vy < 0`) → `player_jump.png`,
  иначе → `player.png`;
- при движении влево спрайт **отражается** по горизонтали.

Если картинка не квадратная и обрезается — поменяй `PLAYER_WIDTH` / `PLAYER_HEIGHT`.

## 2) Небо + земля на старте
- Небо (`background.png`) растягивается **на весь экран один раз** — без швов.
  Лучше всего подходит большая вертикальная картинка (портрет).
- Земля (`ground.png`) — широкая полоса (грунт+трава). Масштабируется по ширине
  экрана **с сохранением пропорций** и повторяется вниз.
- Земля зафиксирована в мире у низа старта (`GROUND_TOP_Y`). При подъёме камера
  уходит вверх, и земля **сама уезжает вниз** — остаётся небо.
- Хочешь видеть больше/меньше земли на старте — меняй `GROUND_TOP_Y` в `constants.py`.

### Про расширения файлов
Имена в `constants.py` заданы как `.png`, но загрузчик принимает и `.jpg/.jpeg/.webp/.bmp`
с тем же именем. То есть `platform_static.jpg` подхватится автоматически.

## 3) Платформы под Minecraft (по типам)
Для каждого типа свой PNG (масштабируется до `PLATFORM_WIDTH × PLATFORM_HEIGHT`,
пиксельно):
- `platform_static.png` — обычная;
- `platform_moving.png` — движущаяся;
- `platform_breakable.png` — ломающаяся;
- `platform_spring.png` — пружина.

Просто положи файлы в `assets/images/` — код сам подберёт нужный спрайт по типу
платформы. Размеры платформ задаются в `constants.py`.

## 4) Оружие, снаряды и игрок с оружием
Три типа оружия (лук/пистолет/автомат) спавнятся по разу на платформах на
высотах 1000 / 2000 / 5000. Картинки нужны трёх видов:

1. **Пикапы** — лежат на платформе (`weapon_bow/pistol/rifle.png`,
   масштаб до `WEAPON_SIZE`, пиксельно).
2. **Снаряды** — летят вверх (`arrow.png` для лука, `bullet.png` для
   пистолета/автомата; размер `PROJECTILE_WIDTH × PROJECTILE_HEIGHT`).
3. **Игрок с оружием** — спрайт игрока зависит от того, что в руках. На каждое
   оружие по две позы (стойка/прыжок), как у обычного игрока. Если файла нет —
   используется плейсхолдер, поэтому можно сначала отрисовать только пикапы и
   снаряды, а модельки игрока добавить позже.

Все имена заданы в `constants.py` (`IMAGE_WEAPON_*`, `IMAGE_PROJECTILE_*`,
`IMAGE_PLAYER_*`). Текущее оружие и перезарядка показываются в HUD.

## 5) Враги
Три типа врагов, у каждого **по одному спрайту** (внешне не меняются),
масштаб до `ENEMY_SIZE`, пиксельно:
- `zombie.png` — зомби (стоит на месте);
- `spider.png` — паук (ездит влево-вправо);
- `skeleton.png` — скелет (ходит вверх-вниз у края, стреляет стрелами `arrow.png`).

Просто положи файлы в `assets/images/` — нужный спрайт подберётся по типу врага.
Стрелы скелета используют уже имеющийся `arrow.png`.

## 6) Фоновая музыка (реализовано)
Игра при запуске включает **зацикленную фоновую музыку**. Положи трек сюда:

```text
assets/sounds/music.ogg
```

Имя задаётся в `constants.py` (`MUSIC_BACKGROUND`), громкость — `MUSIC_VOLUME`
(0..1). Поддерживаются расширения `.ogg`, `.mp3`, `.wav` (имя без расширения
тоже подхватится). Если файла нет — игра просто запустится без музыки.
Музыку проигрывает `AssetManager.play_music`, вызывается из контроллера.

## 7) Короткие звуки (на будущее)
```python
sound = assets.sound("jump.ogg")
if sound is not None:
    sound.play()
```
Форматы: `.ogg` (музыка), `.wav` (короткие эффекты).

## Где взять текстуры в стиле Minecraft
- Нарисовать самому в пиксель-редакторе (Piskel, Aseprite, даже Paint).
- Использовать бесплатные паки (CC0) — главное, проверить лицензию для сдачи.
- Важно для эстетики: маленькое разрешение (16×16 / 32×32) + пиксельное
  масштабирование (уже включено через `smooth=False`).
